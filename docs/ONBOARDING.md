## Project Overview

**NCCL (NVIDIA Collective Communications Library)** is an optimized primitives library for inter-GPU communication. It implements:

- **Collective operations**: all-reduce, all-gather, reduce-scatter, broadcast, reduce, all-to-all
- **Point-to-point**: send/receive based communication patterns
- **Multi-node support**: arbitrary number of GPUs across single or multi-process (MPI) applications

**Languages**: C++, CUDA, Python  
**Build system**: CMake + Makefile  
**Platforms**: PCIe, NVLink, NVswitch, InfiniBand Verbs, TCP/IP sockets

## Key Concepts

### Communication Patterns
NCCL supports two families of communication:
- **Collectives** (all-reduce, all-gather, reduce-scatter, broadcast, reduce): synchronized operations across all ranks in a communicator
- **Point-to-point** (send/recv): direct message passing between specific GPU pairs

### Ring vs Tree Algorithms
The core performance decision. NCCL dynamically selects between:
- **Ring algorithm**: Equal bandwidth utilization, good for moderate message sizes
- **Tree algorithm**: Lower latency for small messages, better scalability at large scale
- The `src/graph/search.cc` module makes this decision based on topology analysis

### Channels
NCCL uses multiple concurrent channels to parallelize communication. Each channel operates independently with its own ring/tree, enabling full bandwidth utilization across NVLink/PCIe links.

### Bootstrap → Transport Selection
1. **Bootstrap** (`src/bootstrap.cc`): Establishes initial TCP/IP connection between all ranks
2. **Topology Discovery** (`src/graph/topo.cc`): Maps GPU interconnects (NVLink, PCIe hierarchy)
3. **Transport Selection**: Picks optimal backend (P2P → SHM → IB → Socket) based on topology
4. **Channel Creation**: Sets up N parallel communication channels

### Device Runtime
The device-side runtime (`src/dev_runtime.cc`) manages GPU memory allocation for collective operations, LSA (Local Scatter All) buffer management, and kernel launch coordination.

## Build & Development Quick Start

```bash
# Clone and build
make -j src.build

# Build with custom CUDA path
make -j src.build CUDA_HOME=/path/to/cuda

# Build for specific architecture (faster)
make -j src.build NVCC_GENCODE="-gencode=arch=compute_90,code=sm_90"

# Run tests (separate repo)
git clone https://github.com/NVIDIA/nccl-tests.git
cd nccl-tests && make
./build/all_reduce_perf -b 8 -e 256M -f 2 -g <ngpus>
```
